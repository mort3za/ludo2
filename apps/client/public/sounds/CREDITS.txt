Game sound effects
==================

All files in this folder are from Kenney's Sound Pack (https://kenney.nl),
released under the Creative Commons Zero (CC0) license — public domain.
You may use, modify, and redistribute them freely, including commercially,
with no attribution required.

Event mapping (renamed from the original Kenney files):

  no-moves.ogg           Synthesized locally (soft descending two-note cue, when a roll yields no legal moves) — CC0
  token-select.ogg  Interface Sounds / click_003
  token-step.ogg    Digital Audio / pepSound1   (play once per step)
  turn-change.ogg   Interface Sounds / bong_001
  my-turn.ogg            Synthesized locally (soft ascending two-note cue, when it becomes the local player's turn) — CC0
  game-start.ogg    Music Jingles (Retro) / jingles-retro_00
  win.ogg           Music Jingles (Retro) / jingles-retro_07
  game-over.ogg          Digital Audio / lowThreeTone
  token-capture-win.ogg  Synthesized locally (rising fanfare, for the attacker) — CC0
  token-capture-sad.ogg  Synthesized locally (descending "sad trombone" sweep) — CC0

Swap any file for a different one from the same CC0 pack if a clip
doesn't fit; keep the filename so no code changes are needed.
